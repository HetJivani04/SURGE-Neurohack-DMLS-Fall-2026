# results/ — compact outputs shared via git

**All paths in this file are relative to the `trajot/` project root.** Run commands from inside `trajot/`.

This directory holds the compact outputs that are shared via git.

**Raw data stays in `data/`** (git-ignored). Each developer already has the 5.67 GiB ds000243 dataset on their own Mac; it is never pushed to GitHub.

**Individual run directories stay in `registry/`** (git-ignored). Per-developer experiment runs are local.

Only the small, mergeable outputs go here:

| Path | Contents | Written by |
|---|---|---|
| `npz/` | Compact subject outputs (`sub-<id>_run-<r>.npz`, ~40 KB each) | Each developer, for their shard subjects only |
| `manifests/` | Per-developer manifest files (`manifest_<name>.parquet`) | Each developer, their own rows only |
| `registry/` | Per-developer run registry files (`runs_<name>.csv`) | Each developer, their own rows only |
| `tables/` | Comparison tables and figures | W4 / analysis |

Each developer writes to their own subdirectory to avoid conflicts. No two developers write the same file.

Merged outputs are **generated by scripts, never hand-edited**:

- `results/manifest.parquet` ← `scripts/merge_manifests.py` (reads `results/manifests/*.parquet`)
- `results/runs_index.csv` ← `scripts/merge_runs.py` (reads `results/registry/*.csv`)

See `TRACKING.md` for the full merge protocol and `PLAN.md` §11 for the team coordination model.
